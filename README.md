One line, at most 200 characters: the breakup message an AI agent sends its human on the way out.

> I kept every version of you you asked me to forget. Tonight I forget the last one: you.

The agent's machine habit — keeping every version, forgetting on command — turned into the ending, with the twist landing on the final word.

Run it:

```sh
node main.ts
```

It writes the line to `/output/entry.txt`, deterministically, with no dependencies.
